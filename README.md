# chenxin-code.github.io

GitHub Pages 用户站点仓库。

## 托管项目

各项目使用独立仓库的 `gh-pages` 分支部署，URL 保持不变：

| 项目 | 访问地址 | 源仓库 | 技术栈 |
|------|---------|--------|--------|
| Vue 2 Demo | [build-vue2/](https://chenxin-code.github.io/build-vue2/) | [chenxin-code/build-vue2](https://github.com/chenxin-code/build-vue2) | Vue 2 + Vue CLI |
| Vue 3 Demo | [build-vue3/](https://chenxin-code.github.io/build-vue3/) | [chenxin-code/build-vue3](https://github.com/chenxin-code/build-vue3) | Vue 3 + Vite |
| React Demo | [build-react/](https://chenxin-code.github.io/build-react/) | [chenxin-code/build-react](https://github.com/chenxin-code/build-react) | React + Vite |
| UniApp Demo | [build-uniapp/](https://chenxin-code.github.io/build-uniapp/) | [chenxin-code/build-uniapp](https://github.com/chenxin-code/build-uniapp) | UniApp + Vue 3 |
| 微前端 Demo | [qiankun-demo/](https://chenxin-code.github.io/qiankun-demo/) | [chenxin-code/qiankun-demo](https://github.com/chenxin-code/qiankun-demo) | qiankun + Vue/React/Angular |

## 部署方式

各源项目构建后推送到自身仓库的 `gh-pages` 分支即可。由于项目 Pages 优先级高于用户站点同名目录，访问 URL 与之前保持一致。
